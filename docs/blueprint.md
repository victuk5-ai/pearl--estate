# **App Name**: Pearl Estate

## Core Features:

- User Authentication & Authorization: Allow property brokers and prospective buyers to register, log in securely, and manage their respective profiles.
- Property Listing Management: Brokers can easily add new property listings (houses and land) with details such as location, price, type, photos, and contact information, and manage their existing portfolio.
- AI-Powered Listing Description Tool: An intelligent tool that assists brokers in generating compelling and descriptive property narratives, enhancing appeal to potential buyers.
- Property Search & Filtering: Buyers can browse properties with advanced search capabilities, including filters for location, property type, price range, and amenities.
- Premium Listing Promotion: Brokers can 'Go Premium' for 10,000 UGX to feature their listings more prominently on the platform, increasing visibility and lead generation.
- Direct Buyer-Broker Communication: Facilitate direct communication between interested buyers and brokers via in-app messaging or contact forms for enquiries on specific properties.
- Dynamic Banner Advertising: Implement a dedicated section at the top of the interface for displaying rotating banner advertisements, offering additional monetization opportunities.
- Property List Display: Display a scrollable list of properties, including examples from Kampala, Entebbe, and Jinja, on the home screen.

## Style Guidelines:

- Primary color: A sophisticated, dark cerulean blue (#1F3E72) for trust and professionalism, anchoring the visual identity. It represents reliability and a contemporary feel.
- Background color: A subtle, very light blue-grey (#F0F4F8) that provides a clean, open, and inviting canvas for property listings.
- Accent color: A vibrant, clear sky blue (#17CAE4) used for interactive elements like links and highlights. The 'Go Premium' button will use a bright orange for high visibility.
- Go Premium button color: Bright orange (#FF8C00) for high visibility and call-to-action.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, slightly techy, and precise appearance, ideal for distinct headers. Body font: 'Inter' (sans-serif) for exceptional readability across various screen sizes, suitable for detailed property descriptions and general text.
- Utilize clean, outlined, and universally recognizable icons that correspond to real estate categories, user actions, and app features, maintaining a professional aesthetic.
- Implement a minimalist and intuitive layout with ample whitespace to ensure property listings and key information are easily digestible and visually appealing. The home screen will feature a banner ad section at the very top, followed by a scrollable list of properties, and a 'Go Premium' button fixed at the bottom. Responsive design will prioritize clarity on both mobile and desktop views.
- Incorporate subtle and smooth animations for transitions, loading states, and interactive feedback, enhancing the user experience without being distracting.
